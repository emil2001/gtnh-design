# Проверка 2026-10-22

Среда нативного запуска: macOS/APFS, JDK 21, Prism и GTNH 2.9.0-RC-2 с lwjgl3ify/SDL. В репозитории нет игровых библиотек или сохранений; сборка Java выполнялась против установленного экземпляра GTNH.

## Выполнено

- **Чистая копия исходников без локального конфига и вызова Java:** семь офлайн-тестов, генерация `example_scene.py` и непустой быстрый рендер прошли. Проверены именованная палитра с локальными IDs 256/4095, metadata, порядок осей, неверные входы, ограничение распаковки Anvil, занятость очереди до запуска Java и отказ использовать worker другого клона.
- **Нативный тест:** `verify_native.py` завершился успешно. Две итерации одного schematic дали по шесть непустых PNG, `gl_error=0`, пустые `renderer_messages` и восемь сохранённых TileEntities. Окно было скрыто, относительный режим мыши выключен. Обе итерации использовали один PID.
- **Изменение сцены:** у ArchitectureCraft изменился материал, у ступени — ориентация/половина. На северо-восточном кадре изменилось 16 880 пикселей, изменения присутствовали на всех шести видах. Нативные кадры осмотрены, видны сложные формы, соединения оград, сундук и прозрачные блоки.
- **Восстановление:** неизвестный registry name вызвал явную ошибку, очередь освободилась, следующий корректный файл отрендерился тем же процессом.
- **Рельеф:** ограниченный участок локальной копии настоящего мира прочитан без записи в источник. Сохранены 95 TileEntity/multipart-записей; 151 ячейка с metadata >255 отмечена в расширении аудита. Этот частный участок не включён в Git.
- **Скилл:** структурная проверка `skill-creator` и `stefania-skill-creator` прошла. Ссылки и команды сверены с toolkit; сценарии будущей агентской оценки приложены отдельно и не выдаются за выполненный независимый benchmark.

## Границы проверки

Это проверка конкретного стенда и платформы, а не всех блоков GTNH. Linux/Windows, другие версии сборки и обычные игровые Entities не проверены. Native — скрытый клиент в графической сессии, которому нужны OpenGL и память сборки. Первичная загрузка большого мира может долго сканироваться VisualProspecting.

Быстрый режим показывает полные кубы и условные цвета. Metadata рельефа >255 в native отображается по младшему байту. Успешный рендер не доказывает, что выбранный инструмент вставки сохранит все IDs/NBT; toolkit не выполняет вставку в пользовательский мир.
