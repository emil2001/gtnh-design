# Проверка 2026-10-22

Нативный рендер проверен на macOS/APFS с JDK 21, Prism и GTNH 2.9.0-RC-2 с lwjgl3ify/SDL. Java-код собран с библиотеками установленной GTNH. Сами игровые библиотеки и сохранения в репозиторий не включены.

## Выполнено

- В чистой копии исходников прошли семь офлайн-тестов, генерация стенда через `example_scene.py` и быстрый рендер. Локального конфига не было, Java не запускалась. Проверены палитра имён с локальными ID 256 и 4095, метаданные, порядок осей, неверные входные данные и предел распаковки Anvil. Также проверены отказ запускать Java при занятой очереди и отказ подключаться к фоновому клиенту другого клона.
- `verify_native.py` завершился успешно. Два рендера одного schematic дали по шесть непустых PNG, `gl_error=0`, пустые `renderer_messages` и восемь сохранённых TileEntities. Окно оставалось скрытым, относительный режим мыши был выключен. Оба рендера выполнил один процесс с тем же PID.
- После смены материала ArchitectureCraft и ориентации/половины ступени изменились все шесть видов. На северо-восточном кадре изменилось 16 880 пикселей. Кадры осмотрены: видны сложные формы, соединения оград, сундук и прозрачные блоки.
- Неизвестное имя блока в реестре вызвало явную ошибку. Очередь освободилась, и тот же процесс отрисовал следующий корректный файл.
- Участок локальной копии настоящего мира прочитан без записи в источник. Сохранены 95 записей TileEntity и составных блоков. В 151 ячейке метаданные выше 255; их исходные значения сохранены отдельно для проверки. Этот частный участок в Git не включён.
- Скилл прошёл проверку структуры через `skill-creator` и `stefania-skill-creator`. Ссылки и команды сверены с инструментами. Сценарии будущей оценки приложены отдельно; независимая проверка работы агента по ним ещё не проводилась.

## Границы проверки

Проверены описанный стенд и платформа. Остальные блоки GTNH, Linux, Windows, другие версии сборки и обычные игровые сущности (Entities) не проверены. Нативный режим работает в скрытом клиенте, которому нужны графическая сессия, OpenGL и память для сборки. При первой загрузке большого мира VisualProspecting может долго сканировать его.

Быстрый режим показывает полные кубы и условные цвета. Метаданные рельефа выше 255 нативный рендер читает по младшему байту. Сохранность ID и NBT при вставке нужно проверять отдельно: эти инструменты не размещают блоки в пользовательском мире.
