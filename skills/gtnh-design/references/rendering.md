# Рендер и диагностика

В корне клона прочитай `README.md` для установки и `config.example.json` для полей путей. Локальный конфиг содержит только пути, не токены. Нужен JDK 21 и установленная GTNH 2.9.0-RC-2 под Prism с рабочим входом Minecraft.

```sh
python example_scene.py
python render_fast.py runtime/example.schematic --output runtime/example-draft.png
python build_native.py
python render_native.py runtime/example.schematic --id calibration-001
python worker.py status
```

`render_fast.py` не использует игровые текстуры и форму блоков. Применяй для расположения масс. Нативный renderer подключает Schematica и модовые renderer, пишет `iso-ne.png`, `iso-nw.png`, `iso-sw.png`, `iso-se.png`, `top.png`, `underside.png` и `result.json` в `runtime/renders/<id>/`. Каждый ID одноразовый. Входной файл нативного режима должен находиться внутри клона.

Для готового задания проверь JSON и **посмотри изображения**, включая обратную сторону или нижний ракурс, если там сложные стыки. Сравни `tile_entities`, `multipart_blocks`, `schematic_dimensions`, ошибки и предупреждения с ожидаемым содержимым schematic. `context_metadata_above_alpha_range > 0` означает ограничение точности части контекста.

Если Java не стартует после первого создания экземпляра, Prism мог не перечитать список папок. Однократный перезапуск Prism помогает; не перезапускай уже работающий renderer ради изменения schematic. Если Prism требует вход, используй обычную авторизацию пользователя, не извлекай токены или launch arguments.

Если worker сообщает неверное окно или захват мыши, останови этот экземпляр и проверь совместимость SDL/lwjgl3ify. Если queue занята, дождись текущего задания; не удаляй активный request и не запускай параллельные задания. После таймаута проверь PID, отчёт задания и состояние очереди прежде чем повторять. Не публикуй сырые launcher logs: они могут содержать авторизацию.

Неизвестные registry names вызывают явный отказ. Отсутствующие TileEntities и renderer warnings — причина исследовать импорт и NBT. Сначала воспроизведи на маленькой сцене, затем проверяй проект целиком.

Рабочие моды/ресурсы связаны с исходным экземпляром, конфиги и сохранение скопированы. После изменения состава модпака останови worker и осознанно пересоздай изолированный экземпляр, сохранив нужные результаты. Для штатной остановки: `python worker.py stop`. Файлы runtime и экземпляр Prism сами при этом не удаляются.

`python verify_native.py` проверяет шесть непустых видов, восемь TileEntities, скрытое окно без захвата мыши, явную ошибку неизвестного блока, восстановление очереди и две итерации одного файла в одном PID. Это проверка стенда, а не гарантия всех моделей GTNH.
