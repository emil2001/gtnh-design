# Рендер и диагностика

Установка описана в `README.md`, поля с путями перечислены в `config.example.json` в корне клона. Локальный конфиг содержит только пути; токенов в нём нет. Для нативного рендера нужны JDK 21 и установленная в Prism GTNH 2.9.0-RC-2 с рабочим входом в Minecraft.

```sh
python example_scene.py
python render_fast.py runtime/example.schematic --output runtime/example-draft.png
python build_native.py
python render_native.py runtime/example.schematic --id calibration-001
python worker.py status
```

Через `render_fast.py` оценивай объём и расположение частей постройки. Он рисует кубы с условными цветами, без игровых текстур и форм. Нативный рендер использует Schematica и средства отрисовки модов. Он сохраняет `iso-ne.png`, `iso-nw.png`, `iso-sw.png`, `iso-se.png`, `top.png`, `underside.png` и `result.json` в `runtime/renders/<id>/`. Для каждого запуска нужен новый ID, а входной файл должен лежать внутри клона.

После рендера проверь JSON и посмотри изображения. Если есть сложные стыки, осмотри их с обратной стороны или снизу. Сверь `tile_entities`, `multipart_blocks` и `schematic_dimensions` с ожидаемым содержимым schematic, проверь ошибки и предупреждения. Если `context_metadata_above_alpha_range > 0`, часть блоков рельефа может отображаться неточно.

Если Java не запускается после создания экземпляра, Prism мог не заметить новую папку. Перезапусти Prism один раз. Для следующих правок schematic работающий рендер перезапускать не нужно. Если Prism требует вход, используй обычную авторизацию пользователя; не извлекай токены и аргументы запуска.

Если фоновый клиент сообщает об ошибке окна или захвате мыши, останови его и проверь совместимость SDL/lwjgl3ify. При занятой очереди дождись текущего задания: не удаляй активный запрос и не запускай параллельные задания. После таймаута проверь PID, отчёт и очередь, прежде чем повторять запуск. Не публикуй исходные логи лаунчера, в них могут быть данные авторизации.

Неизвестное имя блока в реестре вызывает явную ошибку. Если пропали TileEntities или появились предупреждения рендера, проверь импорт и NBT. Сначала воспроизведи ошибку на маленькой сцене, затем проверь весь проект.

Моды и ресурсы подключены из исходного экземпляра, конфиги и сохранение скопированы. После изменения состава модпака останови фоновый клиент, сохрани нужные результаты и пересоздай его отдельный экземпляр. Для штатной остановки используй `python worker.py stop`. Рабочие файлы и экземпляр Prism при этом остаются на диске.

`python verify_native.py` проверяет шесть непустых видов и восемь TileEntities, скрытое окно без захвата мыши, явную ошибку неизвестного блока и восстановление очереди после неё. Два рендера одного файла должны пройти в одном процессе с тем же PID. Проверка охватывает тестовый стенд; все модели GTNH ею не проверяются.
