# Координаты, блоки и NBT

Используй `schematic.py`, `nbt.py` и `world_crop.py`, чтобы сохранить типы тегов NBT и соблюсти формат. Порядок осей в массивах Y,Z,X, в отчётах для пользователя - X,Y,Z. Поля `WEOriginX/Y/Z` задают мировые координаты начала выбранного участка. При переносе TileEntity (TE) меняй `x/y/z` на локальные координаты. Остальные теги и их типы сохраняй.

```sh
python world_crop.py --world /absolute/path/to/local-world-copy \
  --bounds 0 60 0 31 100 31 --output projects/terrain.schematic
python schematic.py projects/terrain.schematic
```

Скрипт только читает мир. Используй копию сохранения после остановки игры или согласованный снимок мира. Границы входят в участок. Поддерживаются секции обычного Minecraft и EndlessIDs в GTNH; реестр блоков берётся из `level.dat/FML/ItemData`. Если чанков нет, скрипт вернёт ошибку. Чтобы совместить рельеф и проект, приведи их к одной системе мировых координат, затем пересчитай локальные координаты итогового объёма. Сохраняй TE исходного рельефа и удаляй их только у заменённых ячеек.

`schematic.write(path, blocks, metadata, palette, tiles, origin)` принимает локальные ID палитры от 0 до 4095 с `minecraft:air=0`. По именам из `SchematicaMapping` они сопоставляются с реальными ID сборки. Сами ID сервера могут быть выше 4095. В GTNH Schematica первое значение `AddBlocks` хранится в старших четырёх битах байта (nibble), а в обычном Alpha WorldEdit - в младших. Скрипт учитывает оба порядка при чтении и сохраняет вариант GTNH с именами блоков.

Для метаданных блока Alpha отводит байт. Значения рельефа выше 255 сохраняются отдельно в `GTNHPreviewMetadata`, но нативный рендер использует младший байт. Если такие блоки важны для дизайна, его точность ещё не подтверждена. Данные `savedMultipart` переносятся в `GTNHPreviewMultipart`, откуда их восстанавливает этот рендер. Другие редакторы могут не поддерживать такую вставку.

ArchitectureCraft хранит форму, ориентацию и исходный материал в TileEntity NBT. Carpenter's там же хранит свои атрибуты. Одних ID и метаданных для этих блоков недостаточно. Для нового типа возьми образец из установленного мода или маленького сохранения и проверь нативным рендером. Не добавляй в публичные примеры владельцев, инвентари, содержимое книг и другие данные игрока. При экспорте частного проекта не удаляй нужный NBT без предупреждения.

Форма ступеней, плит, стен и оград зависит от метаданных и соседних блоков. Бери имена блоков Chisel/EFR из реестра установленной версии. Проверяй стыки и направление по нативным кадрам: быстрый рендер показывает эти блоки полными кубами.

Schematica Printer ставит блоки из предметов и не восстанавливает произвольный TE NBT. Из-за этого разные формы ArchitectureCraft могут превратиться в одинаковые колонны. WorldEdit 6.1.1 ограничен 12-битными числовыми ID и не гарантирует правильную вставку всей палитры GTNH. Прежде чем рекомендовать вставку, проверь выбранный редактор и файл на копии мира. Явно укажи, как обрабатывается воздух, где начало отсчёта и смещение (origin/offset) и в каком направлении идёт вставка. Объём чертежа с воздухом может вырезать склон. Сам набор инструментов только рисует сцены и экспортирует чертежи.
