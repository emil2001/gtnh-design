# Координаты, блоки и NBT

Используй `schematic.py`, `nbt.py` и `world_crop.py`, чтобы не терять типы NBT и соглашения формата. Массивы имеют порядок **Y,Z,X**, размеры в пользовательских отчётах — X,Y,Z. `WEOriginX/Y/Z` фиксируют начало мирового crop. При переносе TE меняй `x/y/z` на локальные координаты, сохраняя остальные теги и их типы.

```sh
python world_crop.py --world /absolute/path/to/local-world-copy \
  --bounds 0 60 0 31 100 31 --output projects/terrain.schematic
python schematic.py projects/terrain.schematic
```

Мир читается только на чтение; используй копию остановленного сохранения или согласованный snapshot. Границы включительные. Поддерживаются vanilla/EndlessIDs секции GTNH; registry берётся из `level.dat/FML/ItemData`. Отсутствующие чанки — ошибка. Для композиции переводи рельеф и проект в одну систему мировых координат, затем пересчитывай локальные координаты итогового объёма. Сохраняй TE исходного рельефа вне заменяемых блоков; удаляй TE только у действительно заменённых ячеек.

`schematic.write(path, blocks, metadata, palette, tiles, origin)` принимает локальные palette IDs 0..4095 с `minecraft:air=0`. Именованная `SchematicaMapping` разрешает их в реальные IDs сборки. Не ограничивай сами registry IDs сервера числом 4095. В GTNH Schematica `AddBlocks` использует старший nibble первым; обычный Alpha WorldEdit — младший первым. Хелпер учитывает это при чтении, а пишет вариант GTNH с именами.

Обычный metadata Alpha — байт. Значения рельефа выше 255 сохраняются отдельно в `GTNHPreviewMetadata`, но native использует младший байт. Если такие блоки важны для дизайна, точность не подтверждена. `savedMultipart` переносится в `GTNHPreviewMultipart` и восстанавливается этим renderer; универсальная вставка другими редакторами не гарантирована.

ArchitectureCraft хранит форму, ориентацию и исходный материал в **TileEntity NBT**, а Carpenter's — свои атрибуты. Данных ID/meta недостаточно. Для нового типа возьми образец из установленного мода или маленького сохранения и проверь нативным рендером. Не добавляй в публичные примеры владельцев, инвентари, содержимое книг или другие данные игрока. При экспортировании частного проекта не удаляй нужный NBT молча.

Ступени, плиты, стены и ограды зависят от metadata и соседей. Используй актуальные registry names Chisel/EFR, не похожие имена из другой версии. Стыки и направление проверяй в нативных кадрах. Быстрый renderer намеренно показывает их полными кубами.

Schematica Printer ставит предметы и не восстанавливает произвольный TE NBT; это известная причина одинаковых ArchitectureCraft-колонн. WorldEdit 6.1.1 имеет предел 12-битных числовых IDs и не гарантирует весь набор GTNH. Перед рекомендацией вставки проверь конкретный редактор и файл на копии мира. Воздух, origin/offset и направление вставки должны быть явными: вставка bounding box с воздухом может вырезать склон. Сам toolkit только рендерит и экспортирует.
